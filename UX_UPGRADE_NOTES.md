# UX Upgrade Notes

This release replaces the minimal proof-of-concept frontend with a polished Command Center interface:

- Sidebar navigation
- Dashboard metrics
- Run command center
- Media intake dropzone
- Manual item capture
- Inventory review cards
- Item detail editor
- Structured URL evidence
- Screenshot evidence parser UI
- Wix CSV / audit export center
- Deployment checklist
- Connector status check

Backend architecture remains Accuracy-First: no silent guessing, evidence-gated pricing, exact Wix CSV export, config-driven profiles, and audit JSON.
