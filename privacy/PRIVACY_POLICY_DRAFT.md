# Privacy Policy Draft — StorageUnit SimLay

Last updated: Replace before launch

StorageUnit SimLay helps users convert storage-unit photos, videos, item notes, and pricing evidence into inventory records, Wix CSV exports, and audit JSON files.

## Data collected or processed
The app may process:

- Photos and videos uploaded by the user
- Item names, categories, conditions, and notes
- Evidence URLs and screenshots supplied by the user
- Generated inventory CSVs and audit JSON exports
- Basic technical logs required to operate and troubleshoot the service

## Purpose of processing
Data is used to:

- Create inventory records
- Help users review item certainty and condition
- Store evidence for pricing decisions
- Generate Wix-compatible CSV exports
- Generate audit trails
- Improve reliability and diagnose errors

## AI processing
If enabled, uploaded media may be sent to the configured AI vision provider through the backend service. API keys are kept server-side and are not stored in the mobile app.

## Data sharing
Data is not sold. Data may be transmitted to service providers required to run the app, such as hosting providers, storage providers, and configured AI/market evidence providers.

## User control
Users should be able to delete runs, uploaded media, inventory records, evidence records, and exports from the hosted application. Confirm final deletion behavior before public launch.
