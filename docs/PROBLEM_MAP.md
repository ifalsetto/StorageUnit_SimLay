# Problem Map — StorageUnit SimLay

## Core Problem
Storage-unit resale decisions are made from incomplete visual evidence, uneven market comps, and strict Wix import formatting needs.

## Axes

1. Visual uncertainty: brands/models/conditions are often not fully visible.
2. Evidence quality: active listings and sold comps are not equal.
3. Deduplication: the same item can appear in multiple photos or video frames.
4. Export exactness: Wix CSV import fails if headers or row shape drift.
5. Reproducibility: every run must preserve the config snapshot that governed decisions.
6. Local-first durability: data must remain usable without depending on live market connectors.

## Governing Values

1. Accuracy over speed.
2. Evidence over assumption.
3. Configurability over hardcoding.
4. Conservative export over optimistic price claims.
5. Local-first persistence.
